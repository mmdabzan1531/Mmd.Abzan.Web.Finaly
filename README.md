# Chatroom | محمد مهدی آبزن

## اجرا
- ویندوز: `run.bat` | مک/لینوکس: `./run.sh` | داکر: `docker compose up -d`
- فایل `.env.example` را به `.env` کپی کن و مقدارها را پر کن (برنامه خودش `.env` را می‌خواند).
- برای تست روی کامپیوتر خودت، بدون تنظیم ایمیل/پیامک، در `.env` بنویس `CHATROOM_DEV_CODES=1` تا کد روی صفحه نشان داده شود. **روی سرور واقعی هرگز.**

## ارسال کد واقعی
| ورودی کاربر | مسیر ارسال | تنظیم لازم |
|---|---|---|
| ایمیل (Gmail و غیره) | ایمیل | `GMAIL_USER` و `GMAIL_APP_PASSWORD` (رمز برنامه ۱۶ حرفی گوگل، با تأیید دومرحله‌ای) |
| شماره ایرانی `09…` | پیامک | `KAVENEGAR_KEY` + `KAVENEGAR_TEMPLATE` یا `SMSIR_KEY` + `SMSIR_TEMPLATE` |
| شماره خارجی `+…` | پیامک | `TWILIO_SID` `TWILIO_TOKEN` `TWILIO_FROM` |

- اگر هاستت پورت SMTP را می‌بندد، به‌جای Gmail از `BREVO_API_KEY` و `BREVO_SENDER` (ارسال با HTTP) استفاده کن.
- کاوه‌نگار: یک قالب «verify» با متنی که `%token` دارد بساز و تأیید شود. حساب آزمایشی فقط به شماره‌ی خود صاحب حساب پیامک می‌فرستد.
- هنگام اجرا، در ترمینال می‌نویسد کدام سرویس READY است و کدام نه.

## صفحه‌ها
`/` ورود · `/signup` ثبت‌نام (شماره یا ایمیل ← کد ← ساخت حساب) · `/forgot` بازیابی رمز (کد ← رمز جدید) · `/about` `/support` `/privacy` `/terms`
اطلاعات تماس را با `SUPPORT_EMAIL` `SUPPORT_PHONE` `SUPPORT_TEL` `SUPPORT_ADDRESS` عوض کن. متن حریم خصوصی و قوانین نمونه است.

## رفع مشکل «در حال ارسال…»
- علت اصلی: اتصال Socket.IO پشت پروکسی هاست (Render و…) به‌خاطر بررسی Origin رد می‌شد، و پیام فقط با پخش همگانی سرور از حالت «در حال ارسال» خارج می‌شد. حالا پیش‌فرض CORS باز است (`CHATROOM_CORS` برای محدود کردن).
- ارسال سه‌مرحله‌ای: تأیید سوکت ← اگر نشد ارسال HTTP (`/api/messages`) ← اگر باز هم نشد پیام «ارسال نشد» می‌شود و با یک لمس دوباره ارسال می‌شود. ارسال تکراری ایجاد نمی‌شود.
- اگر سوکت اصلاً وصل نشود، چت با گرفتن پیام‌ها هر ۳ ثانیه کار می‌کند (ویرایش/حذف/فوروارد فقط با اتصال زنده).
- کلاینت Socket.IO از چند CDN بارگذاری می‌شود؛ برای مطمئن‌ترین حالت فایل `socket.io.min.js` (نسخه 4.7.5) را در `static/vendor/` بگذار.

## کتابخانه‌ها
Flask، Flask-SocketIO، python-socketio/engineio، **simple-websocket** (WebSocket واقعی)، gunicorn (`requirements.txt` قبلاً نبود).
**مهم:** برنامه باید با ۱ worker اجرا شود (چون سوکت و کدها در حافظه‌اند). دیسک دائمی برای `CHATROOM_DATA_DIR` لازم است.

## تم و فونت
۱۶ تم (۱۱ تیره، ۵ روشن + خودکار) و ۳۴ فونت فارسی/عربی گوگل با تغییر اندازه متن؛ فقط فونت انتخاب‌شده دانلود می‌شود. از «تنظیمات» یا پایین صفحه‌ی ورود.
